Description
-----------
OneBank is the bank companion to OneBag. It replaces the default bank UI
with a single combined window for the main bank and all bank bags.

Requires: OneBag (Emberveil edition)

Features (Emberveil)
--------------------
- Main bank + bank bags in one frame
- Separate OneBank Options menu (not shared with OneBag)
- Adjustable columns, scale, and padding
- Rarity coloring and bag-type colors
- Bank bag buttons under the frame (main bank + bags 1–6)
- Click bag buttons to show/hide that bag’s slots
- Position remembered when you move the frame

How to use
----------
1. Install OneBag and OneBank in your AddOns directory.
2. Enable both at the character select screen.
3. Talk to a banker — OneBank opens instead of the default bank.
4. Click Menu on the bank window for OneBank-only options.

Commands
--------
/obb or /onebank — classic slash options (Menu button is preferred)

Notes for Emberveil
-------------------
- Loads with OneBag (not demand-only) so the bank frame is ready.
- Default Blizzard bank frame is hidden while OneBank is active.
- Main bank button uses a fixed icon (there is no bag item for the vault).
